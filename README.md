# Blood Donation Management System

A full-stack blood donation platform built with a Node.js/Express backend and a React + Vite frontend. The system supports donor registration, blood requests, inventory tracking, and appointment management.

## Features
- Donor and recipient management
- Blood request handling
- Inventory and stock tracking
- Appointment scheduling
- Authentication and email verification
- Responsive modern frontend

## Tech Stack
- Backend: Node.js, Express, MongoDB, JWT
- Frontend: React, Vite, Tailwind CSS

## Project Structure
- backend/: API server and business logic
- frontend/: React application
- _legacy/: older static assets and prototype files

## Getting Started

### Backend
```bash
cd backend
npm install
npm start
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

## Notes
- Configure environment variables before running the backend.
- A sample environment file is available in backend/.env.example.
